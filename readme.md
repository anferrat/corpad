# Corpad Cathodic Protection
## Data collection for corrosion professionals

Corpad Cathodoc protection is mobile application that assists in field data collection and generation reports.

- Collect corrosion data with iOS and Android devices
- Use phone's GPS for effective navigation
- Connect Bluetooth multimeter to read voltage and current directly to the app
- Use phone's NFC module to read and write data to the tags
- Capture images with your devices and attach them directly to the test points

## Technologies:
- React Native
- React Navigation
- Redux
